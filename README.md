# TeleZip

Графическое приложение на Python для загрузки и скачивания больших файлов в Telegram (Избранное) с разбивкой на ZIP-фрагменты.

## Возможности

- Приём файлов методом Drag & Drop в главное окно.
- Разбиение исходного файла на ZIP-фрагменты без сжатия по ~3,9 ГБ.
- Отправка фрагментов в "Сохранённые сообщения" Telegram.
- Хранение метаданных в SQLite.
- Скачивание и сборка файлов из Telegram по сохранённым фрагментам.

## Требования

- Python 3.9+
- Установленные зависимости из `requirements.txt`
- Telegram API ID и API Hash

## Настройка

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Первый запуск создаст в каталоге пользователя `~/.telezip` файл `config.json`. Заполните его своими `api_id`, `api_hash` и номером телефона Telegram.
3. Запустите приложение:

   ```bash
   python main.py
   ```

## Примечания

- Телеграм-сессия сохраняется в файле `~/.telezip/telezip.session`.
- Фрагменты временно сохраняются в системной папке `Temp` и удаляются после отправки/скачивания.
- Сборка большого файла требует свободного места в папке `Downloads` пользователя.
